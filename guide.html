Why are images and the map showing as squares in my phone and rectangles on my tablet? I made all the images square to match what was displayed on the phone, now I look on the tablet and the images do not display properly. The distortion happens because of two CSS rules in the guide.html stylesheet: width: 100% with a hard pixel cap max-height: 280px: On a phone, the card width is typically around 320px–360px. A container that is ~340px wide by 280px high is almost square, so square images fit with little cropping. On a tablet, the card width expands up to the full max-width: 680px, but the container remains capped at 280px high. This forces the container into a wide 680×280 landscape rectangle. object-fit: cover: object-fit: cover tells the browser: "Fill the entire container, even if you have to slice off the top, bottom, or sides to avoid empty space." When a square (1:1) image is forced to fill a wide landscape rectangle (roughly 2.4:1), the browser zooms in and crops away over half the image (the top and bottom thirds). The same container logic applies to the map embed (width: 100% and height: 360px), which becomes an elongated letterbox on wider screens. How to Fix It Depending on how you want images to behave across both phones and tablets, update the CSS in guide.html: Option 1: Lock Images to a Square Aspect Ratio Everywhere (Recommended) If your workflow is creating square (1:1) images, enforce a consistent 1:1 aspect ratio regardless of screen width: Replace: CSS /* Card Image */ .card-media { width: 100%; max-height: 280px; overflow: hidden; margin: 10px 0; border-radius: 6px; background: #0b0f19; border: 1px solid var(--border); } .card-media img { width: 100%; height: 100%; object-fit: cover; display: block; } With: CSS /* Card Image - Locked 1:1 Aspect Ratio */ .card-media { width: 100%; aspect-ratio: 1 / 1; overflow: hidden; margin: 10px 0; border-radius: 6px; background: #0b0f19; border: 1px solid var(--border); } .card-media img { width: 100%; height: 100%; object-fit: cover; display: block; } Option 2: Preserve the Full Image Without Any Cropping (contain) If your images have varying proportions (some 16:9 landscape, some 4:3, some square) and you never want parts cut off: CSS .card-media { width: 100%; max-height: 400px; display: flex; align-items: center; justify-content: center; margin: 10px 0; border-radius: 6px; background: #0b0f19; border: 1px solid var(--border); } .card-media img { max-width: 100%; max-height: 400px; width: auto; height: auto; object-fit: contain; display: block; } For the Embedded Map To keep the map from looking like a squashed strip on a tablet, replace the fixed pixel height with an aspect-ratio: CSS /* Replace: .embed-card.map iframe { height: 360px; } */ .embed-card.map iframe { width: 100%; aspect-ratio: 16 / 9; min-height: 320px; } If I follow your advice and use existing images I can't guarantee that an image will always be square.
